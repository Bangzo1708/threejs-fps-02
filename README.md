DUSTLINE is a round-based tactical FPS built on three.js: 5v5 matches against bots, a bomb to plant and defuse, money earned each round and spent in a buy menu, and gunplay where stopping to aim pays — played on the original dusk freight-yard map Yard Nine.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080.
